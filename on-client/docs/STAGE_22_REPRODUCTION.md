## 데이터 보존 계획과 제한

- 원래 작업 폴더와 Git 기록은 새 복제본과 별도로 보존합니다. 원래 폴더를 이동·삭제하거나 복제본으로 덮어쓰지 않습니다.
- 소스와 문서는 지정한 Git 커밋으로 추적합니다. 인증·계정 연결 설정은 프로젝트 밖의 사용자별 설정이므로 복제본으로 무작정 복사하거나 저장소에 넣지 않습니다.
- 이 재현에서 데이터베이스 백업·복원, 사용자별 설정의 백업·복구는 실행하거나 검증하지 않았습니다. 실제 저장 데이터의 위치·보존 기간·복원 가능성은 현재 근거만으로 확정할 수 없습니다.
- 보존·복구가 필요한 데이터는 운영자가 안내한 공식 절차를 확인한 뒤 다룹니다. 이 문서는 백업이 완료됐거나 복원이 가능하다고 주장하지 않습니다.

## 지원 범위·남은 확인

- `0.2.14`는 시작 틀 버전입니다. 본 문서 작성 시점의 결과는 검증 중이며 `v1.0` 또는 운영 인증이 아닙니다.
- 19단계의 실제 보안 조치 집행 연결은 제공 제품 안내에서 미완료로 설명됩니다.
- 새 복제본에서 실행 도구로 실행하고, 브라우저 화면을 확인한 뒤 종료·재실행하는 절차가 남아 있습니다. 그 후 13~21단계별 결과와 증거·확인 시각을 실제 관찰에 따라 갱신해야 합니다.
- 실행 도구의 “계정 연결 설정을 확인하지 못했습니다. 기존 설정과 학생 작업은 그대로 두었습니다.” 문구는 원인·조치가 확인되지 않았습니다. 이 문서에서는 원인을 추측하지 않습니다.
